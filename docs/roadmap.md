# Roadmap

What comes after the soft launch, in the order it will be built. There are no dates: each item
starts when the one before it is done. Ideas and objections go to
[GitHub Discussions](https://github.com/kevinshibuya/promptfall/discussions).

## 1. The public listing and the official marketplace

The public server opens to everyone, not only the invited wave, and Promptfall is offered for the
official Claude Code plugin marketplace, so it installs without adding this repo as a marketplace
first. Until then the two commands in the README install it from here.

## 2. Hero skills and techniques

Heroes gain actions beyond attack and heal: skills and techniques that each hero's tactics pick
when the fight calls for them, the way they already pick a target. It deepens the fight every
party already has, rather than adding a new mode beside it.

## 3. The challenge tower

Your real party, in the gear it wears, climbs floors drawn from a daily seed that everyone shares,
until it wipes. A tower ladder ranks the floor each party reached that day, and the day's reward
arrives as a server event, like a world boss reward.

## 4. Async PvP and ranked

A party fights a snapshot of another player's party, played out on the challenger's side. The
server replays the fight to verify the result, and a rating moves on verified results only.

## 5. Zone packs, classes and items

More of the world: new zones with their enemies and bosses, new hero classes, and new items and
affixes.
